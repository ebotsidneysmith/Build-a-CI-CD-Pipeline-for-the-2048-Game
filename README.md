This project demonstrates the implementation of a CI/CD pipeline to automate the deployment of a Dockerized 2048 game to AWS. The pipeline streamlines the entire lifecycle building, testing, and deploying the application using modern AWS services such as Amazon Elastic Container Service (ECS), Amazon Elastic Container Registry (ECR), and AWS CodePipeline. The goal is to deliver a scalable, reliable, and fully automated deployment solution for containerized applications on AWS.
